#
# Reference:
#   https://jinja.palletsprojects.com/en/stable/templates/
#
# Highlights the Jinja2 template constructs:
#   {{ ... }}    output / expression tags
#   {% ... %}    statement / block tags (if / for / set / block / macro / ...)
#   {# ... #}    comments
#   # ...        line comments (typical in config templates)
#   "..." '...'  strings
#   numbers
# and colors every builtin filter, test and global function as a builtin name.
